# 설정 화면

프로젝트 전체에 걸리는 입력값을 모은 화면입니다. 왼쪽 목차에는 불러온 뒤 바꾼 항목 수가 노란 숫자로 나오고, 아래 **불러온 값으로 되돌리기**로 설정만 한 번에 되돌립니다(노드·연결선은 그대로, Ctrl+Z로 다시 돌림).

| 칸 | 정하는 것 |
|---|---|
| 프로젝트 | 설계서에 나오는 이름 |
| 구동 방식 | 웹·앱·로컬 실행 등. 방식에 따라 계산하는 항목이 달라집니다(로컬 실행은 서버 부하 대신 기기 메모리). |
| 규모 | 활성 사용자 수, 이벤트 배수, 보관 기간, 목표 사용률, 시드, 큐 적체 계산 단위(고정 대수 소비자, 1·5·15·60분) |
| 하루 피크 | 업종(외식·배달, 라이브 게임, 출퇴근, 업무용, 쇼핑, OTT)을 누르면 피크 시각과 페르소나 비율이 함께 바뀝니다. 그래프의 봉우리를 끌어 시각·폭·비중을 고칩니다. **일시적 급증**을 켜면 하루 횟수·이어지는 시간·높이(1.5배까지)를 정합니다. |
| 페르소나 | 사용 패턴별 사용자 무리와 비율(분포의 봉우리를 끌어 정함), 나라, 접속 횟수·시간 |
| 행동 | 주문·리뷰처럼 사용자가 하는 일, 그때 쓰는 테이블과 행 수, 페르소나별 빈도 |
| 데이터 주고받기 | 폴링·스트리밍, 최신화 주기, 모아 보내기. 서비스 성격별 추천값을 제안합니다. |
| 성장 | 월 성장률 또는 유입 모형(바깥 유입·입소문·페르소나 단계 이동), 보는 기간, 준비 기간 |
| 비용 기준 | 기본 리전, 저장·송신·리전 간 전송에 쓸 가격 상품 |
| 장애 목표 | 견딜 장애(없음·존·리전), 목표 RTO·RPO. 정하면 노드 판정에 들어갑니다. |

각 값이 계산에 어떻게 쓰이는지는 [계산 방식](model.md)에 있습니다.

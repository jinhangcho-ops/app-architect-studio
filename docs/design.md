# 설계도 화면

위쪽 **설계도 / 설정**에서 설계도를 고르면 나오는 화면입니다. 가운데 캔버스, 아래 그래프, 오른쪽 결과 패널로 나뉩니다. 위쪽 줄의 패널 단추로 아래·오른쪽을 접을 수 있고, **다이어그램만**을 누르면 둘 다 접힙니다.

## 캔버스

- **블록과 연결:** 화면·게이트웨이·백엔드·캐시·큐·배치·DB·외부·분석 레이어의 블록을 놓고 끌어서 잇습니다. 연결선마다 동기/비동기, 호출 비율, 읽기·쓰기만, 왕복 지연을 정합니다.
- **카드:** 블록마다 판정 색, 사용률 막대, 단일 장애점 표시가 붙습니다.
- **자동 배치 · 3D 보기:** 카드를 다시 늘어놓거나, 레이어를 입체로 봅니다.
- **세부 구성:** 카드를 누르면 그 블록 안으로 들어가고 오른쪽에 그 블록이 선택됩니다. Esc나 오른쪽 클릭으로 나옵니다.
  - 서버 블록: 대수와 분배 방식
  - DB·캐시·분석 블록: 테이블·컬럼·인덱스. SQLite로 직접 실험할 수 있습니다.
  - 부품: 주 항목과 보조 항목을 끌어 놓아 바꿉니다.
  - 화면 블록: 와이어프레임. 데스크톱·태블릿·모바일 화면을 끌어 놓기로 그리고, HTML 파일을 그대로 가져오고, PNG로 저장합니다. 버튼에 붙인 API 호출이 연결선과 부하 계산으로 이어집니다.

## 아래 그래프

- 핵심 숫자: 서버 트래픽, DAU, 창 안 접속, 피크·이벤트 피크 RPS, 하루 송신
- 하루 서버 사용률 곡선, 사용자 유입, 페르소나 단계, 사용자가 늘 때 한계에 닿는 곳

## 오른쪽 결과 패널

### 선택한 것
고른 블록이나 연결선을 고칩니다.

| 칸 | 내용 |
|---|---|
| 기본 · 선택 항목 | 이름, 레이어, 주 항목·보조 항목 |
| ★ 판정 근거 | 항목마다 됨·조건부·안 됨·판단 불가와 이유, 통과하는 대안 |
| 📊 계산 결과 | 부하, 대당 처리량, 필요 대수, 사용률, p99, 가용성, DB 연결 수, 한계 사용자, 파이프라인 줄(큐 지연·배치 실행·자동 확장 대수) |
| 목표로 찾기 | 목표(가용성·비용 등)에 좋은 항목을 판정과 함께 보여 주고 바로 적용 |
| 사양·운영 | vCPU·메모리, 이중화·최소 대수, 1대 가용성, 처리 시간, 캐시 적중률, DB 연결 풀, 큐 파티션·허용 지연, 소비자 자동 확장, 배치 주기·실행 창, 과금 상품 |
| 장애 대비 | 존 수, 다른 리전 복사본(같이 받기·대기·백업), 백업 주기·시점 복구·되살리는 속도와 그 결과 |
| 데이터 위치·개인정보 | 리전, 개인정보 속성 → 확인할 법 조문 |
| 직접 넣는 값 | 엔진이 계산하지 않는 판정 변수나 실측값 |

### 전체 결과
규모, 페르소나별 트래픽, 테이블 크기, 확장 한계, 경로(가용성·월 중단·리전 장애), 월 비용, 구조 규칙, 확인할 조문, 판정 요약.

### 최선 조합
목표 우선순위와 꼭 지킬 조건(월 예산, 한계 사용자, p99, 가용성)을 정하면 블록마다 항목을 바꿔 가며 조합을 찾고, 비용–한계 그래프와 추천 조합을 보여 줍니다.

계산 방식은 [계산 방식](model.md)에 있습니다.

# 저장 · 불러오기 · 설계서

## 파일 메뉴
- **예시 불러오기:** 예시 프로젝트(`examples/*.json`)를 엽니다.
- **열기 / 파일로 내보내기:** 프로젝트를 JSON으로 열고 저장합니다.
- **코드 분석 불러오기:** `tools/analyze_py.py`가 파이썬 코드를 분석해 만든 JSON을 합칩니다(서비스·워커 후보).
- **저장 기록:** 저장한 시점 목록. 시점으로 되돌리거나 자동 저장 간격을 바꿉니다.

## 저장
- 직접 저장(Ctrl+S)은 저장 기록에 시점을 남깁니다(최대 20개).
- 자동 저장은 고칠 때마다 최신 시점을 덮어쓰고, 간격(기본 10분)마다 새 시점을 만듭니다(최대 10개).
- 강제로 닫혀도 다시 열면 복구를 제안합니다. 데스크톱 앱은 프로젝트 폴더에도 시점 파일을 남깁니다.
- 브라우저 저장소가 꽉 차면 오래된 시점부터 지우고, 그래도 못 쓰면 알려 줍니다.

## 설계서 PDF
위쪽 **설계서 PDF**를 누르면 A4 설계서가 열립니다. 판정 근거, 노드 카드(계산 결과·파이프라인·장애 시나리오), 한계·비용, 최선 조합, 화면 설계, 확인할 조문, 출처가 들어갑니다.

## 단축키

| 키 | 동작 |
|---|---|
| Ctrl+S | 저장 |
| Ctrl+Shift+S | 파일로 내보내기 (JSON) |
| Ctrl+O | 파일 열기 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 하기 |
| Ctrl+F | 노드·항목·테이블·컬럼 찾기 |
| Ctrl+C / Ctrl+V | 노드 복사 / 붙여넣기 |
| Esc | 설계서 닫기 → 세부 구성에서 나오기 → 선택 해제 |

## 명령줄
`npm run judge -- examples/global-commerce.json`은 같은 계산을 글로 출력합니다(판정, 노드별 결과, 데이터 파이프라인, 장애 시나리오, 경로, 월 비용, 성장).

`tools/fetch_prices.py`는 클라우드 공식 가격 API에서 한국·일본 리전 가격을 받아 `data/prices/` 형식으로 저장합니다.

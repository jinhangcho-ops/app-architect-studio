# 저장 · 불러오기 · 설계서

## 파일 메뉴

| 메뉴 | 하는 일 |
|---|---|
| 예시 불러오기 | 예시 프로젝트(`examples/*.json`)를 엶 |
| 열기 / 파일로 내보내기 | 프로젝트를 JSON으로 열고 저장 |
| 코드 분석 불러오기 | `tools/analyze_py.py`가 파이썬 코드를 분석해 만든 JSON을 합침 (서비스·워커 후보) |
| 저장 기록 | 저장한 시점 목록. 시점으로 되돌리거나 자동 저장 간격을 바꿈 |
| 인터페이스 명세 내보내기 | 연결선의 명세를 표준 파일로: REST → `openapi-노드.json` (OpenAPI 3.0, 인증·에러 응답 포함), gRPC → `노드.proto`, 메시지 → `asyncapi.json` (AsyncAPI 3.0), 받는 노드가 FastAPI면 `노드_fastapi.py` (pydantic 모델 + 엔드포인트 뼈대, 각 함수는 501, 에러·인증 실패·요청 검증 실패를 모두 problem+json으로 돌려줌. 띄우면 `/docs`가 내보낸 OpenAPI와 같음). 응답 필드가 없는 인터페이스는 204(본문 없음)로 적습니다. 파일·전문은 `layout-보내는-받는-ID.csv` (장 형식·인코딩·레코드 길이, 필드 순서·길이·시작·끝·맞춤·채움. 길이가 빠진 필드부터는 위치를 비움). 이름의 영문·숫자·_ 밖 글자는 `_`로 바뀌고, 이름이 겹치면 `-2`, `-3`이 붙습니다. 데스크톱 앱은 폴더를 골라 한 번에, 브라우저는 파일마다 내려받기 |
| 스키마(DDL)·데이터 사전 내보내기 | DB 노드마다 `schema-노드.sql` (CREATE TABLE·INDEX, NOT NULL·DEFAULT·PK·코드 값 CHECK, 주석). 방언은 주 항목으로: PostgreSQL(Neon·Supabase·CockroachDB 포함, COMMENT ON) · MySQL 8.0.13 이상(줄 안 COMMENT, TEXT·JSON 기본값은 괄호 식, 키로 쓰는 길이 없는 문자열은 VARCHAR(255), 255바이트가 넘는 고정장은 VARCHAR) · SQLite(libSQL 포함, `--` 주석, 정수로 저장하는 시각은 epoch 밀리초·날짜는 1970-01-01부터 날 수) · 그 밖의 SQL DB는 표준에 가까운 형태(열 저장 분석 DB는 CREATE INDEX 없음). MongoDB·DynamoDB와 캐시 노드는 DDL 없이 데이터 사전에만. 그리고 `data-dictionary.csv` (컬럼마다 논리명·DB 타입·필수·기본값·PK·도메인·코드 값·개인정보·쓰는·읽는 기능, 엑셀용 BOM. `= + - @`로 시작하는 글자 칸은 엑셀이 수식으로 읽지 않게 앞에 `'`를 붙임). 파티션·보관 기간은 DDL에 넣지 않음 |

## 저장

| 종류 | 언제 | 남기는 수 |
|---|---|---|
| 직접 저장 (Ctrl+S) | 누를 때 | 시점 20개 |
| 자동 저장 | 고칠 때마다 최신 시점을 덮어쓰고, 간격(기본 10분)마다 새 시점 | 시점 10개 |

- 강제로 닫혀도 다시 열면 복구를 제안합니다. 데스크톱 앱은 프로젝트 폴더에도 시점 파일을 남깁니다.
- 브라우저 저장소가 꽉 차면 오래된 시점부터 지우고, 그래도 못 쓰면 알려 줍니다.

데스크톱 앱은 **원자적으로** 저장합니다. 저장 중에 앱이 꺼져도 원본은 예전 내용 그대로입니다.

```mermaid
sequenceDiagram
  participant A as 앱
  participant T as 임시 파일 (같은 폴더)
  participant F as 프로젝트 파일
  A->>T: 새 내용 쓰기
  A->>T: 디스크에 확정 (fsync)
  T->>F: 이름 바꾸기로 한 번에 교체
  Note over F: 도중에 꺼지면 원본이 그대로 남음
```

## 새 버전 알림

설치 앱은 열 때 새 버전을 한 번 확인합니다(기본 켜짐, **설정 › 앱 › 앱을 열 때 새 버전 확인**으로 끄고 켬).

```mermaid
flowchart LR
  A["앱 열기"] --> B{"확인 켜짐?<br/>설치 앱·버전 앎?"}
  B -- 아니오 --> Z["묻지 않음"]
  B -- 예 --> C["releases/latest가<br/>넘어가는 태그"]
  C --> D{"지금보다 새것?"}
  D -- 아니오 --> Z2["알림 없음"]
  D -- 예 --> N["RELEASE_NOTES.md 받기<br/>(못 받으면 노트 없이)"] --> E["위쪽 알림<br/>새 버전 vX가 있어요 [업데이트]"]
  E --> F["창: vA → vB에서 바뀐 것<br/>[지금 업데이트] [나중에]"]
  F -- 지금 업데이트 --> G{"자동 저장 됨?<br/>공간 충분?"}
  G -- 아니오 --> R["이유를 알리고 하지 않음"]
  G -- 예 --> H["설치 파일 · .sha256 받기"] --> I{"지문 같음?"}
  I -- 아니오 --> X["실행하지 않고 지움"]
  I -- 예 --> J["조용히 설치 (/S --force-run /D=설치 폴더)<br/>앱 닫기 → 설치 뒤 다시 열림"]
```

| 묻지 않는 경우 | 개발 실행, 버전을 모름(1.1.0-local처럼 숫자가 아닌 조각), 태그 없이 만든 시험 빌드(0.0.0), 설정에서 끈 경우 |
|---|---|
| GitHub에 보내는 요청 | 최신 릴리스 주소(HEAD) 하나, 새 버전이면 노트 하나. **지금 업데이트**를 누르면 설치 파일·지문 |
| 버전 비교 | 점으로 나눈 숫자 튜플(1.10 > 1.9). 태그는 `v` + 영문·숫자·`.+-`만 받음 |
| 업데이트 안전 장치 | 지문(.sha256 첫 낱말)이 맞을 때만 실행, 다르면 지움. 설치 프로그램이 2초 안에 실패 코드로 끝나면 앱을 닫지 않고 알림 |

릴리스 노트는 글자로만 보여 줍니다(`##`·`###` 머리는 ■). 인터넷이 안 되면 조용히 넘어갑니다. 코드 서명이 없어서 처음 설치할 때 Windows 경고가 나올 수 있습니다.

## 릴리스 만들기

1. [CHANGELOG.md](../CHANGELOG.md)에 `## v버전` 절을 **추가 · 개선 · 삭제** 세 칸으로 씁니다(바뀐 것이 없으면 "- 없음").
2. `package.json`의 `version`을 같은 값으로 올리고 `v버전` 태그를 push합니다.
3. GitHub Actions가 시험·빌드 뒤 설치 파일, `.sha256`, `RELEASE_NOTES.md`(CHANGELOG에서 그 절만 뽑음)를 올리고, 릴리스 설명 첫 줄에 지문을 적습니다. 절이 없으면 릴리스하지 않습니다.

## 파일 형식 버전

저장 파일에는 `format_version`(지금 2)이 들어갑니다. 버전이 없는 옛 파일은 1로 봅니다. 2는 v1.2.0에서 장 형식·데이터 사전·파일·전문·테이블 연결이 더해지며 올렸습니다(1 → 2는 바꾸는 값 없음). 필드를 더할 때도 버전을 올립니다: 옛 앱이 열고 저장하면 모르는 필드가 사라지기 때문입니다.

```mermaid
flowchart LR
  O["파일 열기"] --> V{"format_version"}
  V -- "앱보다 낮음" --> M["MIGRATIONS로 차례로 바꿈"] --> OK["열림"]
  V -- "같음" --> OK
  V -- "앱보다 높음" --> X["열지 않음<br/>앱을 업데이트하라고 알림"]
```

새 버전 파일을 열지 않는 이유: 이 앱이 모르는 값은 버려진 채로 다시 저장되어 사라지기 때문입니다.

## 설계서 PDF

위쪽 **설계서 PDF**를 누르면 A4 설계서가 열립니다.

| 절 | 내용 |
|---|---|
| 1~4 | 요약, 구동 방식, 규모 가정, 구조도 |
| 5 | 화면 설계 · API 호출 · 인터페이스 명세 (연결선마다 방식·경로·필드·크기·피크 호출, 파일·전문은 장 형식·인코딩) |
| 6 | 데이터 명세 (기능별 테이블, 테이블마다 데이터 사전) |
| 7 | 노드별 선택과 판정 근거 (계산 결과·파이프라인·장애 시나리오 카드) |
| 8~10 | 확장 한계·지연·월 비용, 최선 조합, 가용성·성장 |
| 11~14 | 확인할 조문, 미해결 목록, 적용한 설정, 카탈로그 출처 |

## 명령줄

```bash
npm run judge -- examples/global-commerce.json
```

같은 계산을 글로 출력합니다: 규모(테이블별 하루 행 포함), 노드별 결과, 데이터 파이프라인, 인터페이스 명세 점검(방식·장 형식·레코드 길이), 기능별 테이블, 장애 시나리오, 동기 경로, 월 비용, 성장, 판정, 구조 규칙, 확인할 조문. 파일을 내보내지는 않습니다(내보내기는 앱의 파일 메뉴).

`tools/fetch_prices.py`는 클라우드 공식 가격 API에서 한국·일본 리전 가격을 받아 `data/prices/` 형식으로 저장합니다.
